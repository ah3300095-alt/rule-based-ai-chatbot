# Rule-Based AI Chatbot 🤖

A simple rule-based AI chatbot built in Python as part of **Project 1** of the DecodeLabs Artificial Intelligence Internship.

## 📌 Project Overview

This chatbot responds to predefined user inputs using Python's **if-else statements** and **dictionary-based logic**. It runs continuously until the user enters an exit command.

The purpose of this project is to understand the fundamentals of Artificial Intelligence by implementing a basic rule-based conversational system without using machine learning.

---

## ✨ Features

- Responds to greetings such as **Hello** and **Hi**
- Answers simple predefined questions
- Displays a help menu
- Handles unknown inputs gracefully
- Runs in a continuous conversation loop
- Exits cleanly when the user types **bye**, **exit**, or **quit**
- Uses dictionary-based response mapping
